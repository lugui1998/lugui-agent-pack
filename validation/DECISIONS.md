# Release decisions

`1.0.0` uses Luna Medium as the main coordination default and Luna Low for
unnamed helpers. Each named role pins its model and reasoning effort.

These settings are deliberate defaults, not claims of universal optimality.
The evaluator keeps artifact acceptance, configuration validity, routing
observations, and token accounting as separate concerns. Missing or incomplete
runtime evidence remains unknown rather than being inferred.

The repository publishes the reusable evaluation definitions and tests, but
not local session transcripts, generated run outputs, or machine-specific
validation archives.
